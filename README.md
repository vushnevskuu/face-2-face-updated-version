## Настройка отправки формы

Для работы формы регистрации нужно настроить Web3Forms:

1. Перейдите на https://web3forms.com
2. Зарегистрируйтесь и получите бесплатный токен
3. Замените `YOUR_TOKEN_HERE` в файле `.env.local` на ваш токен
4. Переопубликуйте сайт

Форма будет отправлять письма с данными:
- ФИО
- Наименование компании  
- Должность
- Телефон
- Email

После отправки показывается модальное окно с предложением перейти в Telegram канал.
